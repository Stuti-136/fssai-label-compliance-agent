About the Project

FSSAI Food Label Compliance Checker.

Project Overview

This project is a decision-support demonstration for structured packaged food label information. It uses an API workflow to validate submissions, retrieve relevant regulatory evidence and generate findings with citations.

Assessment Workflow

Frontend → FastAPI → Research queue → Evidence retrieval → Assessment → Results and citations.

Important Disclaimer

This application is not an FSSAI certification, legal opinion or approval to print a food label. A qualified regulatory professional must verify current rules and make the final decision. Automated category workflows may be limited; other categories can be escalated for human review.
